資料匯入／匯出

JSON 用於備份與移轉；Excel 與 PDF 依正式附件格式輸出。

匯出 JSON

備份目前瀏覽器內的全部演練紀錄，後續可匯回本系統或銜接 Firestore。

匯入 JSON

將備份資料匯入並取代目前資料；執行前會再次確認。

匯出 Excel

包含「附件原格式」與「明細資料」兩個工作表，供列印與後續統計使用。

匯出 PDF

以 A4 直式、原附件表格結構輸出；瀏覽器會開啟列印視窗，請選擇另存為 PDF。
