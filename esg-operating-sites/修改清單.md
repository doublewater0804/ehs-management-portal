# R0.1 修改清單
日期：2026-11-26。基準：使用者上傳 ZIP（commit 標記 4a433bfdc08caef963aa0c3e890d0497aae56709），未連線比對正式 GitHub。

- 修改 `index.html`、`portal/app.js`：更新版本引用。
- 修改 `portal/model.js`：ESG 排在環保管理後。
- 修改 `portal/builtins.js`：以既有登錄機制新增營運據點，不覆蓋既有雲端目錄。若已有同 ID 或同路徑之入口，既有設定優先。
- 新增 `esg-operating-sites/index.html`、`style.css`、`app.js`、`cloud.js`、`model.mjs`、`xlsx.mjs`、`model.test.mjs` 與交付文件。首頁按鈕沿用既有 CSS 及標準 ID，靜態放在標題列最後方，不修改其他系統的共用 JS。
- 原 11 欄、無年度分割、雲端修改時間（台灣時間顯示）、異動歷史、回收區、搜尋篩選、統計、選單管理、共用可拉伸備註。
- 匯入解析「台化」工作表，不匯入樞紐分析；比對先依系統 ID 或全欄相同，其他疑似配對須人工確認。缺少的原資料保留。匯出第12欄系統ID，供可靠回匯；其餘管理資訊分工作表。PDF 為瀏覽器列印另存，A3 橫式。
- 地區保留原文，預設標準化香港/澳門與臺灣字樣，可編輯標準地區。各月異動紀錄由歷史時間篩選。不自動推算實體據點總數。
- 採本地 OOXML 讀寫，不依賴額外 Excel CDN；只支援 .xlsx，需現代瀏覽器的解壓 API。匯入上限每批200筆異動。
- 原始 Excel、測試輸出與測試中的內部資料不納入部署包。
- 原有 Firebase 設定、Rules、登入、其他子系統、GitHub Actions、原資料均不修改。
