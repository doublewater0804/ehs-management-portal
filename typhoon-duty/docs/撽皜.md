# 安衛處颱風值勤管理系統 R0 驗收清單

## 1. 基本運作
- [ ] URL可開啟，未出現404；版本顯示R0。
- [ ] 可從系統固定「回 EHS 首頁」返回入口。
- [ ] 桌機／iPad／iPhone排版可使用，手機選單可展開。
- [ ] DEMO模式顯示醒目的示範警語，無正式Firebase寫入。
- [ ] GitHub新子資料夾不覆蓋既有網站、子系統或路由。

## 2. 各廠區及人員
- [ ] 麥寮、彰化、龍德、新港、台北五廠區都可建立事件。
- [ ] 可以新增／編輯／停用人員；各廠區名單不互相顯示。
- [ ] 不設整日共用值勤人員；七個時段可分別選擇一人或多人。
- [ ] 各時段切換時值勤人員及Checklist資料不互相覆蓋。
- [ ] 歷史通報保留當時的人員姓名及內容快照。

## 3. Checklist與通報
- [ ] 08:00–09:00、00:00必須填各單位應到及實到人數。
- [ ] 出勤人數不一致時不可誤判出勤「正常」，須填原因。
- [ ] 12:00–13:00納入上午巡查；16:00–16:30納入下午巡查。
- [ ] 天候危險時可選未巡查但須填安全原因，不要求冒險。
- [ ] 19:00、00:00、07:00可產生獨立中夜班完整通報。
- [ ] 備勤結束前另有最後確認Checklist。
- [ ] 未確認Checklist、異常無說明、未填風雨資料均不可儲存為完成通報。
- [ ] 正式通報可複製；變更內容後必須重新儲存正式版。
- [ ] 不會將未確認自動改成「正常」。

## 4. 異常與規定
- [ ] 可建立即時異常、是否群組回報／聯絡主管／外部附照片及改善狀態。
- [ ] 不在系統上傳附件，也不自動發送LINE。
- [ ] 公告欄分章節收錄PDF本文、通報範例及手寫批示閱覽指引。
- [ ] 可開啟原始3頁PDF，不改寫原件。
- [ ] 管理員可新增、修改、刪除備註，修訂版本保留歷程。
- [ ] 追加內容與原核定條文分離，不將辨識不確定手寫文字當核定原文。

## 5. Firebase安全及資料
- [ ] config.js填寫現有Firebase Web App設定與管理員UID。
- [ ] Rules片段**合併**到舊規則；舊EHS其他路徑正常。
- [ ] 管理員可建立、更新、刪除；其他登入者唯讀。
- [ ] 未登入者不可讀寫；確認沒有更寬鬆通用規則覆蓋限制。
- [ ] 重新整理後資料仍存在；不同裝置登入可讀到相同資料。
- [ ] 更新前端版本不清空Firestore資料。
- [ ] 測試資料刪除前已確認無誤。

## 6. 匯出／回復
- [ ] 匯出.xlsx以Excel打開，事件／回報／Checklist／出勤／異常／值勤人員六張工作表可閱讀。

- [ ] 知道GitHub前端回退不會自動恢復已刪除Firestore資料。
