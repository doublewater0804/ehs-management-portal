EHS 智慧行事曆 R0.5.1｜修正與補齊部署版本

本版以 R0.5 為基準，保留「全年度全月份共用備註」及既有 Firebase 舊備註整合流程。

修正
1. 當日行程「出差/公出」顯示順序改為緊接「請假」之前；分類篩選列表同步套用此順序。
2. 修正 display.js 舊版殘留造成的跨日時間顯示排序不一致。
3. 更新 R0.5.1 版本識別及 JS/CSS 載入參數，以利辨識新舊頁面。
4. 備註標題固定為「備註」，保留整合舊月份備註及手動儲存。

不修改 Firebase 既有行程、分類或月份備註；不修改 EHS 其他子系統、Firestore Rules 或後端排程。

部署：將本 ZIP calendar/ 內的 6 個檔案覆蓋對應資料夾（shared-notes.js 如不存在則新增）。
部署後應看到頁首 R0.5.1、備註標題「備註」及「整合舊月份備註」按鈕。
如仍顯示「月份備註」，請檢查 GitHub Pages 的發布來源和網頁快取，勿操作舊版備註進行資料遷移。
