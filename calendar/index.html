分類管理

匯出 Google 日曆

以 .ics 格式輸出當月或自訂日期區間（最多一年），套用目前分類及搜尋篩選。未填完整結束時間的活動需先補齊，否則會顯示略過。重複活動限於選取日期範圍。

Google 日曆 ICS 匯入預覽

只匯入預覽中勾選的活動；複雜週期及例外日期會明列警告、不會自動簡化。

Discord 提醒設定

每筆活動可另設自訂分鐘數。自動通知使用 GitHub Actions 排程；Webhook 和 Firebase 管理憑證只能存 GitHub Secrets。未設定 Secrets 時無法實際發送。
