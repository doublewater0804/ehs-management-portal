# 安衛處颱風值勤管理系統 R0

**2026-10-23**。純靜態 GitHub Pages 前端，沿用既有 Firebase Authentication 與 Firestore；請先閱讀 [部署說明.txt](部署說明.txt)。

功能：五廠區（麥寮、彰化、龍德、新港、台北）獨立颱風事件及人員名單；日班三個通報時段和中、夜班19:00／00:00／07:00；可依時段多選值勤人員；08:00–09:00及00:00核對出勤人數；上、下午巡查安全確認；颱風結束下哨前檢查；異常紀錄；完整版通報預覽、LINE文字複製；真正.xlsx Excel匯出；可增修訂的「颱風值勤規定」公告欄與歷程。原始2025/11/12 PDF含手寫核示，以唯讀檔案完整保留。

原報告對於台北廠區未列規定的值勤人數，本系統**不自行新增規定**。掃描手寫批示部分難以辨識，保留原圖供確認，而非使用推測轉錄文字。

不包含：圖片附件上傳、PDF報表、自動LINE傳送、即時氣象及CEMS/CWMS連動、Dashboard、逾時通知。

系統預設 `config.js` 中 `mode: 'demo'`，僅在目前瀏覽器使用 localStorage 試操作；正式部署必須填入同一 EHS Firebase專案參數、管理員UID，將 Rules片段合併到現有規則，並切換 `mode: 'firebase'`。前端權限不足以保護Firestore，真正讀寫權限由已驗證的安全規則強制執行。

原PDF以原始影像為核定參考；網頁章節版是閱讀整理，備註及補充修訂均另外保留，不覆寫原件。
