# 每周安全永續組工作重點

EHS 管理入口平台 → 綜合管理 → 每周安全永續組工作重點。

## 功能

- 預設開啟第一張 Sheet「2026年職災事故統計表」，另外有「TO 劉協理」等分頁；若有更多 Sheet 自動增加。
- 支援匯入 `.xls`、`.xlsx`、`.xlsm`，不將公司 Excel 放進公開 GitHub。
- 盡量保留 Excel 的儲存格色彩、合併儲存格、欄寬、列高、文字數值格式；複雜格式不保證 100% 等同原始 Excel。
- 手動修改所有非公式儲存格、新增及刪除整列（合併儲存格區間及公式受損情形會阻止）。
- 上傳新版先與畫面當前資料比較差異，可逐格保留或採用新版；布局異動時只可採用整份新版，避免錯位合併。
- 公式儲存格唯讀。已支援一般引用、四則運算、SUM/IF/COUNT/COUNTA/MIN/MAX/AVERAGE/ROUND/ABS 等，其他公式提示「需用 Excel 重新計算」。
- 報表日期（手動設定）與最後正式發布日期分別顯示。
- 只有管理者 `doublewater0804@gmail.com` 可登入瀏覽、編輯、儲存及下載。真正權限由 Firebase Rules 控制。
- 下載最新正式版本為 `.xlsx`，已包含線上已發布的修改；為保護正式資料，尚未發布編輯不包含在「正式版下載」中。
- 發布時保留最新一版雲端檔案，成功後刪除舊版（極端中斷情形見規則附錄）。

## 已更新的入口網站檔案

- `/portal/builtins.js`：註冊新系統，保證舊版 Firebase 雲端入口清單也能顯示本模組。
- `/portal/defaults.json`：增加系統預設資料。
- `/portal/app.js`、`/index.html`：更新快取版本參數。
- `/weekly-focus/*`：本模組程式。

## 部署（不破壞既有系統）

1. 備份遠端 `doublewater0804/ehs-management-portal` 目前 `main` 分支。
2. **先**在 Firebase 控制台依 `FIREBASE_RULES_ADDENDUM.md` 將規則合併至原規則；不可直接整份覆蓋。
3. 將「增量更新包」檔案合併上傳至 GitHub `main` 分支根目錄（不要刪除原有其他系統）。
4. 等待 GitHub Pages 更新，開啟：`https://doublewater0804.github.io/ehs-management-portal/weekly-focus/index.html`。
5. 透過入口 `https://doublewater0804.github.io/ehs-management-portal/index.html#general` 進入新系統。
6. 使用原 Google 管理者登入。按「上傳新版 Excel」上傳真正的公司 Excel，選擇報表日期，確認差異並按「儲存並發布修改」。
7. 下載最新版 Excel 驗證第二張 Sheet 公式和文字格式。

**請勿把含機密數據的原始 `.xls` 檔案提交到 GitHub Pages。**

## 重要使用限制

- 網頁使用 `xlsx-js-style@1.2.0` 外部 CDN 載入 Excel 解析程式；需可正常連上 jsDelivr、Firebase。此程式碼基於 SheetJS 0.18.5，支援基本樣式，不是完整 Excel 引擎。
- `.xls` 讀入再轉 `.xlsx` 的格式、公式、列印設定、圖片、圖表、條件式格式、特殊資料驗證、巨集等，可能遺失或變更；**不可保證 100% 保留原始檔版面與完整 Excel 功能**。特別是原始檔的跨工作表公式，請正式啟用前先以 Excel 比對結果。
- `.xlsm` 會失去 VBA 巨集，應避免匯入含必要巨集的檔案。
- 網頁僅重算常見公式；不支援或有外部連結的公式可能仍顯示舊快取值，會明確警示。請在 Excel 開啟輸出檔讓 Excel 重新計算。
- 目前頁面分批展示最多 160 列，仍可翻頁與編輯；單張工作表最高 1400 列、90 欄，單檔大小 10 MB。超過此規模需升級虛擬表格。
- 合併儲存格區間不允許插入/刪除整列；原始工作表整體結構改變時，不允許舊、新資料逐格合併。
- Firebase Storage 和 Firestore 在寫入流程無跨服務交易，網路中斷仍可能留下未引用的舊檔。若需絕對只留 1 檔，可加後端清理程序。
- 由於 GitHub Pages 是公開的靜態網站，網頁程式本身可以被存取；私人 Excel 的保密性完全仰賴 Firebase Rules。
- 如遠端主分支較本次提供的上傳備份新，請優先使用「增量更新包」並只合併這幾個相關檔案，避免覆寫新版入口網站程式。

## 驗收

先完成以下三種獨立檢查，再允許放正式敏感檔：

1. **程式結構檢查**：JavaScript 語法、HTML 入口連結、更新檔案清單。
2. **離線單元測試**：雙 Sheet 引用、非公式編輯、列操作、差異保留、刪除參照保護。
3. **Firebase 線上實測**（部署後由管理者完成）：正確帳號可用；未登入及錯誤帳號不得讀/寫；上傳/重整/下載的兩張 Sheet 與更新時間一致。

本包不包含你的真實 Excel，公司機密不會預先送上公開 GitHub。
